English to Hindi Language Translator

About the Project

This project is a simple language translation web application built with Python and Streamlit. It allows users to translate English text into Hindi using the MyMemory Translation API.

Features

- Translate English text into Hindi.
- Simple and user-friendly interface.
- Free online translation service.
- Displays the translated text directly in the application.

Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API

Installation and Setup

1. Install Python on your computer.

2. Install the required libraries:
   
   python -m pip install -r requirements.txt

3. Run the application:
   
   python -m streamlit run app.py

4. Enter English text and click Translate to Hindi to see the translation.
